# Void Corkboard

A Foundry VTT module (v13/v14) that adds a detective corkboard: pin journals, journal pages, handouts, characters, Party Notes and index cards to cork, and tie them together with labelled string. Boards sync live and players can use them with no GM online.

Install in Foundry Setup, Install Module, with this manifest URL:

    https://raw.githubusercontent.com/zecatte/void-corkboard/main/module.json

Open the board with the pushpin button in the left toolbar, the Corkboard button at the top of the Journal sidebar, Shift+B, or the pushpin button on any journal window.

Ping: Shift+click anywhere on the board to show every player a pulsing marker in your colour.

Magnifier: hold Left Alt (or press Shift+M, or click the magnifying-glass button on a journal or image window or in the left toolbar) and hover over any image; the lens shows it enlarged from the full-resolution file. Mouse wheel changes the zoom. Keys are rebindable in Configure Controls. Works for every player, no Keeper needed.

All board data is stored in the world (journal flags in the "Corkboards" folder). The module folder holds only code.
